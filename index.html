Title
Algorithm Types: 8 Machine Learning Algorithms Grouped by Type of Learning
Introduction
Machine learning consists of different types of algorithms and each one is used to solve a different problem. Before picking the algorithm, we see if the data is labeled or unlabeled and whether to predict a datapoint, a category or group similar items or if its to simplify the data. The infographic puts 8 common algorithms into one picture so that these choices are easy to see.
Description
This is an infographic that groups 8 ML algorithms by their type and classifies whether it is a supervised or an unsupervised algorithm. Supervised algorithms use labeled data as their training data and unsupervised algorithms can detect patterns and trends by exploring the data themselves. The training data for unsupervised algorithms have no labels. Each algorithm has a card of its own showing which category it belongs to, what it does, where it is used and the real world examples.
Figure 1: Algorithm Types · Created with Claude and draw.io
  • 1. Linear Regression (Supervised, Regression)
    How it works: Tries to fit a straight line through the data points by making the distance between the line and each data point as small as possible. The next value is predicted by looking along the line.
    Domain: Sales forecasting, real estate pricing
    Examples: Estimating a house price from its size and location; forecasting next month's sales from ad spend
    Output: A number
  • 2. Logistic Regression (Supervised, Classification)
    How it works: Works like linear regression, then squeezes the result through an S-shaped curve to get a probability between 0 and 1. Above 0.5 means yes, below means no.
    Domain: Healthcare, banking and email filtering
    Examples: Classifying an email as spam or not spam; deciding if a borrower is likely to default on their loan; assessing a patient's disease risk
    Output: Yes/No and its probability
  • 3. Decision Tree (Supervised, Classification)
    How it works: Asks a chain of yes/no questions starting at the top, and each answer takes the prediction down to a different branch.
    Domain: Banking, medicine, customer support, retail
    Examples: Deciding on giving a loan at a bank; steps for triaging a patient's symptoms; choosing which customers get targeted offers
    Output: A category or number
  • 4. Random Forest (Supervised, Classification)
    How it works: Builds many decision trees based on different features and slices of data. The different trees then vote. The crowd cancels out a tree if the others don't agree with its decision.
    Domain: Finance, e-commerce, bioinformatics, satellite imagery
    Examples: Catching credit card fraud; predicting which customers would cancel the card
    Output: A category or number
  • 5. Support Vector Machine (SVM) (Supervised, Classification)
    How it works: Draws the dividing line with the widest possible gap (margin) between two classes.
    Domain: Text and image recognition, bioinformatics
    Examples: Reading handwritten digits; sorting news articles by topic; telling cancerous cells from healthy ones
    Output: A category
  • 6. K-Nearest Neighbors (KNN) (Supervised, Classification)
    How it works: For a new point, it finds the K closest neighbors and takes a majority vote of their labels. There is no training step involved with this algorithm.
    Domain: Recommendations, pattern recognition, finance
    Examples: Suggesting movies liked by similar viewers; recognizing handwritten characters; flagging unusual credit behavior
    Output: A category or number
  • 7. K-Means Clustering (Unsupervised, Clustering)
    How it works: Chooses K centre points and assigns every item to its nearest centre. It then moves each centre to the average of its group. This is repeated until all the groups stop changing.
    Domain: Marketing, retail, image processing
    Examples: Splitting customers into segments by buying habits; reducing an image to a few of its colors; grouping news stories together in a news app
    Output: Groups of items
  • 8. Principal Component Analysis (PCA) (Unsupervised, Dimensionality Reduction)
    How it works: Finds new axes along which the data varies the most, then keeps only the top few. It is used to reduce the dimensionality of the data.
    Domain: Image processing, finance, data visualization
    Examples: Removing noise from sensor data
    Output: Reduced dimensionality
How they connect
  • Logistic Regression vs Linear Regression: Logistic regression takes the idea of a straight line from linear regression and bends it by adding a probability.
  • Random Forest vs Decision Tree: A Random Forest has many Decision Trees which vote, so a single tree's habit of memorizing the data is fixed.
  • KNN vs K-Means: KNN uses labels, whereas K-Means groups items together from an unlabeled dataset.
  • PCA is usually a helper: PCA is often used to reduce the dimensionality of the data, and other algorithms like K-Means or KNN are used later for prediction.
Objective
  • To list out 8 common ML algorithms and show how they are connected and how they work
  • To state their application domain and at least one real world example
  • Explain how each algorithm works
